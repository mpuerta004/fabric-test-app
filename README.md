## Test application for FABRIC evaluation 

Test application comprised of:
- Data generator: Generates a random 1-100 integer every 1 second.
- Data collector: Python code with REST endpoint.

Data generator is run as ./send_random.sh. Data collector is run using the Docker Compose file.

This application was generated for an evaluation of the FABRIC Compute Continuum platform, presented in: _Gorka Nieto et al._ FABRIC: A Standards-Aligned Orchestration Platform for Compute Continuum Operations in 5G Networks and Beyond. _Under review in Frontiers in Computer Science._
